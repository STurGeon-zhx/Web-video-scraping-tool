# 唯品会商品主视频适配设计

## 目标

让现有视频批量下载工具接受以下唯品会商品详情链接，并下载商品详情顶部展示的公开主视频：

`https://detail.vip.com/detail-<品牌ID>-<商品ID>.html`

首个真实验收链接为：

`https://detail.vip.com/detail-10007920-6921967044893585744.html`

## 范围

- 仅支持唯品会 `detail.vip.com` 的商品详情页。
- 仅提取商品详情顶部的商品主视频。
- 不提取买家评论视频、推荐商品视频或广告视频。
- 仅处理无需登录即可访问的公开内容。
- 不读取用户现有 Edge、Chrome 或其他浏览器的 Cookie、历史记录和个人资料。
- 本次同步更新源码程序和项目根目录的单文件 `视频批量下载工具.exe`，不修改安装包。

## 解析方案

唯品会商品页的静态 HTML 只包含视频模板，真实 `shortVideoUrl` 由页面加载后的公开商品详情接口动态返回。适配器仅在识别到唯品会商品详情链接时启动一个全新的无登录 Edge 临时上下文：

1. 校验输入必须是安全公网 HTTPS 地址，域名必须为 `detail.vip.com`，路径必须符合商品详情格式。
2. 使用 Playwright 通过系统 Edge 启动无持久化、无登录的临时浏览器上下文。
3. 监听唯品会商品详情接口响应，并只读取与当前商品 ID 对应的数据。
4. 从商品基础数据中取得商品标题、`shortVideoUrl` 和可选封面。
5. 校验视频地址为公网 HTTP/HTTPS 媒体地址，拒绝本机、局域网、保留地址和异常跳转。
6. 将结果转换为现有 `yt-dlp` 下载适配层可使用的统一视频信息，并附带唯品会商品页 Referer。
7. 关闭临时浏览器上下文，不保留登录信息或站点资料。

唯品会解析器只在唯品会商品链接上启用，不影响抖音、快手、B 站和公网视频直链。

## 数据与界面

- 任务平台标识新增 `vipshop`，界面展示为“唯品会”。
- 视频 ID 使用商品 ID，去重键继续采用 `(platform, video_id)`。
- 文件名优先使用唯品会返回的商品标题；标题为空时使用 `唯品会视频_<商品ID>`。
- 输入提示增加唯品会商品详情链接说明。
- 现有数据库结构无需迁移，仅保存新的平台字符串。

## 错误处理

- 链接格式错误：返回“不支持的唯品会链接”。
- 商品无主视频：返回“该唯品会商品没有可下载的主视频”。
- 匿名页面加载或接口响应失败：返回“唯品会匿名访问失败，请稍后重试”。
- 视频地址未通过公网安全校验：按访问受限处理。
- 超时和网络错误沿用现有三次重试与指数退避机制。

## 测试与验收

- 单元测试覆盖链接匹配、商品 ID 提取、动态响应解析、主视频选择、无视频错误、安全视频地址和平台标识。
- 集成测试使用模拟匿名浏览器响应验证批次展开、任务创建和下载适配器注册。
- 完整运行后端和前端自动化测试，确认现有平台无回归。
- 使用用户提供的唯品会商品链接创建任务并完成真实下载，验证文件可播放且包含声音。
- 关闭旧程序，启动最新源码程序并验证页面/API。
- 重新构建项目根目录 `视频批量下载工具.exe`，实际启动打包后的 EXE，验证唯品会链接可识别并创建任务。

## 运行约束

- 唯品会解析依赖 Windows 10/11 自带或已安装的 Microsoft Edge。
- 不绕过登录、验证码、付费或访问控制；如匿名访问触发验证码，任务失败并给出明确提示。
- 平台页面和接口规则可能变化，发生变化时通过发布新版适配器处理，不在运行时静默更新代码。
