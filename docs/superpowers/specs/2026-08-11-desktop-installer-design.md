# 抖音批量下载桌面安装版设计

## 目标

将现有“EXE 启动本地服务并打开外部浏览器”的工具改造成真正的 Windows 桌面客户端，并交付单个安装程序。安装后用户通过桌面快捷方式或开始菜单启动独立窗口，不需要安装 Python、Node.js、浏览器运行时或 FFmpeg。

“离线使用”指软件界面、设置、历史记录、任务恢复和本地文件管理可以在断网时运行；解析和下载抖音视频必须联网。首版支持 Windows 10/11 64 位。

## 技术方案

采用 PySide6、QtWebEngine、FastAPI、Vue 3、SQLite、yt-dlp、FFmpeg、PyInstaller 和 Inno Setup。

选择 PySide6/QtWebEngine 的原因是 QtWebEngine 自带渲染引擎，不依赖接收方电脑是否安装 Microsoft WebView2 或特定浏览器。相比 Electron，它能够复用现有 Python 后端，减少双运行时和进程间桥接的复杂度。

PyInstaller 使用目录模式而非单文件模式。目录模式不需要每次启动都把百兆资源解压到临时目录，启动更快，也降低杀毒软件扫描、临时目录权限和残留进程造成的问题。Inno Setup 将该目录压缩为一个可分发的 `Setup.exe`。

## 桌面运行架构

Qt 主线程负责桌面窗口、系统原生目录选择和单实例通信。FastAPI/Uvicorn 在后台线程启动，仅监听随机的 `127.0.0.1` 端口。QtWebEngine 加载该本地地址并显示现有 Vue 界面，用户不会看到或依赖外部浏览器。

启动顺序：

1. 创建 Qt 应用并尝试注册本地单实例服务。
2. 如果已有实例，向已有实例发送“显示窗口”消息并立即退出。
3. 初始化本地数据目录、SQLite、下载器和工作队列。
4. 在后台线程启动 Uvicorn，等待端口可访问。
5. 创建主窗口并加载 Vue 页面。
6. 主窗口关闭时通知 Uvicorn 安全退出，等待工作器和服务器结束后退出 Qt 应用。

Qt 窗口是程序生命周期的唯一依据。现有基于浏览器 SSE 的“页面断开后自动退出”逻辑不再用于桌面入口，避免浏览器连接抖动造成程序误退出。

## 桌面窗口

主窗口复用现有页面布局和交互，默认尺寸适配常见 1366×768 及以上屏幕，并支持最小化、最大化和调整尺寸。窗口标题为“抖音批量下载工具”。

目录选择接口由 Qt 原生 `QFileDialog` 实现。后端线程通过线程安全桥接请求 Qt 主线程打开对话框，并等待选择结果。打开下载目录继续使用 Windows 文件管理器。

程序不提供外部网页地址，不监听局域网地址，不上传链接、Cookie、历史记录或视频文件。

## 单实例与退出

使用 `QLocalServer`/`QLocalSocket` 实现本地单实例通信，不再以 Windows Mutex 作为唯一控制手段。第二次启动安装版时，已有窗口会恢复、置顶并获得焦点。

关闭窗口时：

- 停止接受新任务；
- 正在处理的任务恢复为等待状态并保留断点文件；
- Uvicorn 最多等待 5 秒结束连接；
- Qt 最多等待限定时间后退出，不能长期残留后台进程；
- 下次启动继续读取同一 SQLite 数据库并恢复任务。

## 数据与离线行为

应用数据继续保存在 `%LOCALAPPDATA%\DouyinBatchDownloader`，包含 SQLite、设置、运行日志和匿名临时访问上下文。下载文件保存在用户选择的目录。

断网时可以打开程序、查看历史批次、修改本地设置和打开已下载文件。创建下载任务后如果网络不可用，任务进入“网络错误”并按现有规则重试，不导致界面或程序退出。

卸载程序删除安装目录和快捷方式，但默认不删除应用数据与已下载视频，避免用户数据丢失。

## 安装程序

Inno Setup 生成中文安装向导，默认安装到当前用户的 `%LOCALAPPDATA%\Programs\DouyinBatchDownloader`，不要求管理员权限。

安装程序包含：

- 桌面客户端目录及其全部依赖；
- QtWebEngine 运行资源；
- Python 运行时和后端代码；
- Vue 生产资源；
- yt-dlp、Playwright 驱动和 FFmpeg；
- 桌面快捷方式、开始菜单入口和卸载程序。

安装完成页允许直接启动工具。首版不包含自动更新和代码签名；未签名安装包可能触发 Windows SmartScreen，使用说明必须明确提示。若后续提供代码签名证书，可在构建流程中签名安装程序和主程序。

## 打包与版本

PyInstaller 新增桌面目录模式规格文件，与现有开发运行方式分开。Inno Setup 脚本读取目录模式产物并生成版本化安装程序，例如：

`抖音批量下载工具-Setup-1.0.0-Windows-x64.exe`

构建脚本按以下顺序执行：前端测试、前端生产构建、后端测试、PyInstaller 目录构建、安装程序编译、安装包结构和哈希校验。

## 错误处理与日志

桌面启动阶段的异常写入 `%LOCALAPPDATA%\DouyinBatchDownloader\application.log`，并使用桌面消息框显示简短中文提示。后端接口错误继续显示在页面内。

重点处理：QtWebEngine 资源缺失、内部端口启动失败、数据库初始化失败、目录选择线程错误、FFmpeg 缺失、单实例通信失败和退出超时。任何错误都不能只表现为无窗口或 `Failed to fetch`。

## 测试与验收

自动化测试覆盖：

- 桌面启动配置和数据目录；
- 后台服务线程启动与停止；
- 单实例激活消息；
- Qt 关闭事件触发安全退出；
- 原生目录选择桥接；
- 断网任务进入网络错误且程序保持运行；
- PyInstaller 产物包含 QtWebEngine、Vue、yt-dlp 和 FFmpeg；
- Inno Setup 脚本包含当前用户安装、桌面快捷方式和卸载项。

成品验收使用隔离的全新用户数据目录，并在干净 Windows 10/11 64 位环境完成：

1. 安装程序无需管理员权限完成安装。
2. 桌面快捷方式打开独立窗口，不启动外部浏览器。
3. 断网时可以打开界面并查看本地历史。
4. 联网后使用授权的公开链接完成真实下载，文件可播放且有声音。
5. 暂停、继续、失败重试和重启恢复正常。
6. 重复启动只显示同一个窗口。
7. 关闭窗口后进程按时退出，重新启动成功。
8. 卸载后安装目录和快捷方式移除，下载文件与应用数据保留。

只有以上自动化测试、安装验收和真实下载验收全部通过，安装包才作为最终交付物。
