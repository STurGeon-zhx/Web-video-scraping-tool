# 页面关闭退出与历史抽屉设计

## 目标

- 最后一个工具页面关闭后，自动结束本地程序运行。
- 页面刷新不误触发退出。
- 多个工具标签页同时打开时，仅在最后一个标签页关闭后退出。
- 将页面底部的大型批次历史区域改为右上角入口和右侧抽屉。

## 页面生命周期

后端新增专用的页面生命周期 SSE 接口。每个打开的工具标签页在挂载后建立一条长连接，后端据此维护当前活动页面数量。

规则固定为：

1. 至少有一个页面成功连接后，才启用自动退出判断，避免服务启动但浏览器尚未打开时提前退出。
2. 页面连接断开后减少活动页面数量。
3. 最后一条页面连接断开时启动 3 秒宽限计时。
4. 宽限期内有页面重新连接时取消退出，因此刷新页面不会结束程序。
5. 宽限期结束且活动页面数仍为零时，调用现有安全关闭回调。
6. 多标签页场景下，关闭其中一个页面不会影响其余页面或程序。

程序退出时沿用 FastAPI 生命周期关闭下载队列。未完成任务仍保存在 SQLite 中，下一次启动时由现有恢复逻辑重新进入等待状态。

前端在页面挂载时创建生命周期连接，在 Vue 卸载时主动关闭；即使浏览器没有执行卸载钩子，网络连接断开也会由后端识别。该连接只传递保活信息，不包含链接、Cookie 或视频数据。

## 历史任务抽屉

顶栏隐私提示右侧增加紧凑按钮：`历史批次 N`，其中 N 为本机历史批次数量。

点击后从页面右侧打开抽屉：

- 桌面端使用固定宽度的右侧面板；移动端占据大部分屏幕宽度。
- 页面底部现有大型历史面板删除，历史数据只在抽屉中展示。
- 抽屉保留“新建批次”、批次状态统计、查看、删除和分页功能。
- 点击“查看”后关闭抽屉并展示对应批次详情。
- 点击“新建批次”后关闭抽屉，沿用现有重置、回到顶部和聚焦链接输入框行为。
- 点击遮罩、关闭按钮或按 `Esc` 关闭抽屉。
- 抽屉打开时禁止背景页面滚动，关闭后恢复。

历史数据仍由现有 `GET /api/batches` 等接口提供，不修改数据库结构，也不新增 IP、账号或云端存储。

## 错误与边界处理

- 生命周期 SSE 短暂断线时，浏览器自动重连；3 秒宽限期避免网络抖动或刷新导致误退出。
- 程序已开始退出时不再接受新的下载任务，由现有服务关闭流程完成队列收尾。
- 历史加载失败时保留页面现有错误提示，不影响关闭抽屉。
- 删除当前正在查看的批次时，继续沿用现有关闭批次进度 SSE 和清空详情逻辑。

## 测试与验收

- 单元测试覆盖页面连接计数、最后连接断开后的延迟退出、宽限期重连取消退出，以及多连接只关闭一个时不退出。
- API 测试覆盖生命周期 SSE 注册及断开后的关闭回调。
- 前端测试覆盖抽屉开关状态、`Esc` 关闭和“新建批次”继续重置当前页面。
- 浏览器验收确认右上角显示历史按钮、页面底部不再显示历史面板、抽屉内现有操作完整可用。
- 打包后验证刷新页面不退出、关闭最后一个页面后程序结束、重新启动后未完成任务恢复。

## 不在本次范围

- 不增加托盘图标或最小化到托盘行为。
- 不在页面关闭时继续后台下载。
- 不修改下载解析、重试、文件命名或本地数据隔离逻辑。
