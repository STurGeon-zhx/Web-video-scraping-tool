# 一键删除所有批次设计

## 目标

在批次历史抽屉增加“一键删除所有批次”按钮。用户确认后，取消点击时已存在的全部批次，清理未完成任务的临时分片，并删除这些批次及任务的 SQLite 记录；已完成视频和保存目录保持不变。

## 方案

- 新增 `DELETE /api/batches`，先读取当前全部批次 ID，再逐个调用队列已有的 `cancel_batch(batch_id)`，最后逐个调用存储层已有的 `delete_batch(batch_id)`。
- 使用点击时的批次快照，避免并发新建的批次被意外删除。
- 返回 `{"deleted": true, "count": N}`；没有历史时返回成功且 `count` 为 `0`。
- 前端在历史总数同行右侧放置红色描边按钮。确认文案明确说明取消未完成任务、清理分片、保留成品文件及不可撤销。
- 删除期间禁用按钮并显示“正在删除…”。成功后关闭当前任务 SSE、清空详情、重新加载历史第一页，并显示保留成品文件的成功提示。

## 验证

- API 测试验证全部批次都先被取消再删除、成品文件保留、空历史幂等成功。
- Vue 测试验证确认文案、单次批量请求、忙碌状态和成功后的界面重置。
- 运行全部 Python 测试、前端测试和 Vue 生产构建。
