# 新建批次与本地隔离设计

## 目标

- 删除页面顶部的“退出程序”按钮。
- 在“批次历史”标题区域右侧增加“新建批次”按钮。
- 保证每台电脑只显示自身本地数据库中的批次。

## 交互设计

点击“新建批次”后：

1. 清空链接输入内容及其预览结果。
2. 清除当前页面选中的批次详情，但不删除批次记录。
3. 关闭当前批次的 SSE 页面连接。
4. 滚动到页面顶部并聚焦链接输入框。
5. 已经排队或正在下载的任务继续由本机后台队列处理，可从批次历史重新查看。

按钮放在“批次历史”标题右侧、“共 N 个批次”统计左侧。移动端时按钮与统计信息自动换行。

## 本地数据边界

不新增 IP 字段或服务器端用户体系。现有程序只监听 `127.0.0.1`，SQLite 数据库位于当前电脑、当前 Windows 用户的本地应用数据目录，因此不同电脑和不同 Windows 用户天然使用不同批次数据。

## 测试与验收

- 页面不再渲染“退出程序”按钮。
- “新建批次”按钮位于批次历史标题区域。
- 点击后输入、预览和当前详情清空，并聚焦链接输入框。
- 点击后不调用删除、取消或停止队列接口。
- 本地数据库路径和 `127.0.0.1` 监听配置保持不变。
