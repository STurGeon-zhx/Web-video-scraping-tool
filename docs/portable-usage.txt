视频批量下载工具（Windows x64 便携版）

使用方法：
1. 将压缩包完整解压到本地文件夹，请勿直接在压缩包内运行。
2. 双击“视频批量下载工具.exe”启动。
3. YouTube 用户请先配置“YouTube 网络”并点击“测试连接”。
4. 首次使用或提示验证失效时，点击“打开登录验证”，完成后点击“完成验证”。
5. 仅下载本人拥有版权或已经获得授权的公开视频。
6. 点击顶部版本号可以手动检查更新；下载并校验完成后，确认重启即可更新。

稳定性说明：
- YouTube 页面采集与下载使用同一网络出口和工具专用登录状态。
- 不读取日常 Edge/Chrome 的 Cookie。
- 出现连续访问限制时，工具会暂停批次，避免剩余任务全部失败。
- 支持断点续传；请勿删除下载目录中的 .douyin-part 临时目录。
- 不会启动时自动检查或静默更新，更新包必须通过 SHA-256 校验。

运行环境：
- Windows 10 / Windows 11 64 位。
- 无需安装 Python、Node.js、FFmpeg 或 Deno。
- 页面验证依赖系统安装 Microsoft Edge。
